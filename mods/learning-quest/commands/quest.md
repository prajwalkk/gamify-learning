Use the learning-quest skill to run this. Arguments: $ARGUMENTS

- No arguments: run today's coached session (kickoff, reading, goal block, close).
- `board`: show the Quest Board (get_board) in a few short lines.
- `log`: log a sitting I've already done; ask only for what's missing.
- `leave …`: add a leave for the dates given.
- `feeds`: show my feeds and let me change them.
- `setup`: run onboarding.
